# Panduan Upload Pertemuan 8 ke GitHub

Unggah folder ini ke root repository dengan nama:

```text
08_evaluasi-uts-cpmk51-52
```

Struktur folder disamakan dengan Pertemuan 1–7:

- `materi/` untuk slide briefing dan review UTS;
- `panduan/` untuk panduan pelaksanaan UTS;
- `evaluasi/` untuk kisi-kisi, soal, rubrik, dan template jawaban;
- `src/` untuk starter code praktik;
- `tugas/` untuk checklist, instruksi, dan format pengumpulan;
- `assets/` untuk diagram pendukung.

Setelah upload, pastikan file `README.md` tampil di GitHub dan semua dokumen dapat diunduh mahasiswa.
