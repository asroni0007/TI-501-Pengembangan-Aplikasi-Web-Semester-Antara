# Rubrik Penilaian UTS TI-501

| Komponen | Skor Maks | Kriteria Baik |
|---|---:|---|
| Pemahaman konsep web modern | 20 | Jawaban menjelaskan peran teknologi secara tepat dan terhubung dengan studi kasus |
| Analisis kode dan debugging | 25 | Mampu menemukan masalah, memperbaiki kode, dan menjelaskan alasan teknis |
| Desain REST API | 25 | Endpoint konsisten, method tepat, request-response jelas, status code sesuai |
| Praktik mini | 30 | Aplikasi berjalan, HTML/CSS/JS rapi, Fetch aktif, endpoint dapat diuji |
| **Total** | **100** |  |

## Konversi Singkat

- 85–100: Sangat baik
- 70–84: Baik
- 55–69: Cukup
- <55: Perlu perbaikan
