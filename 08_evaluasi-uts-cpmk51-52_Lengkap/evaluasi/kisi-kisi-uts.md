# Kisi-Kisi UTS TI-501 Pertemuan 8

## Identitas

- Mata kuliah: Pengembangan Aplikasi Web (TI-501)
- Pertemuan: 8
- Bentuk evaluasi: Ujian Tengah Semester
- Cakupan: Pertemuan 1–7
- Bobot RPS: 15%
- CPMK: CPMK51 dan CPMK52

## Cakupan Materi

| No | Materi | Fokus Evaluasi |
|---:|---|---|
| 1 | Pengantar web modern dan SDLC | Siklus pengembangan, peran frontend-backend, Web2 vs Web3 |
| 2 | HTML semantik | Struktur dokumen, semantic tags, form dasar, aksesibilitas |
| 3 | CSS responsif | Box model, Flexbox, Grid, media query, layout responsif |
| 4 | UI/UX dan prototyping | Wireframe, usability, alur pengguna, desain inklusif |
| 5 | JavaScript DOM dan Fetch | Event handling, DOM manipulation, async request, JSON |
| 6 | Node.js dan Express | Runtime, routing, middleware, static file serving |
| 7 | REST API | Resource, endpoint, HTTP method, status code, kontrak endpoint |

## Bentuk Soal Disarankan

| Bagian | Bentuk | Bobot |
|---|---|---:|
| A | Pilihan ganda/benar-salah/menjodohkan konsep | 20 |
| B | Analisis kode dan debugging singkat | 25 |
| C | Desain endpoint dan kontrak REST API | 25 |
| D | Praktik mini menggunakan starter code | 30 |
| **Total** |  | **100** |

## Indikator Keberhasilan

Mahasiswa dinyatakan tuntas apabila mampu menjelaskan konsep, membaca dan memperbaiki kode sederhana, merancang endpoint REST API yang konsisten, serta menunjukkan integrasi dasar frontend-backend menggunakan JSON.
