# Pertemuan 8 — Evaluasi Tengah Semester (UTS) CPMK51–52

**CPMK51–52 · Evaluasi konsep dan praktik pengembangan aplikasi web · Studi kasus Asisten AI untuk UMKM**

## Capaian Evaluasi

Mahasiswa mampu menunjukkan penguasaan materi Pertemuan 1–7 melalui soal konseptual dan praktik singkat yang mencakup pengembangan web modern, HTML/CSS, JavaScript, Node.js/Express, serta REST API berbasis JSON.

## Kesesuaian RPS

Materi ini sesuai Pertemuan 8 RPS TI-501:

- evaluasi capaian CPMK51–52 melalui Ujian Tengah Semester;
- cakupan materi Pertemuan 1–7;
- pengembangan web, HTML/CSS, JavaScript, Node.js/Express, dan REST API;
- studi kasus pengembangan aplikasi web “Asisten AI untuk UMKM”.

## Cara Menggunakan Paket

1. Gunakan slide pada folder `materi/` untuk briefing dan review singkat sebelum UTS.
2. Gunakan dokumen pada folder `panduan/` sebagai panduan resmi ujian.
3. Gunakan folder `evaluasi/` untuk kisi-kisi, soal paket A/B, rubrik, dan template jawaban.
4. Folder `src/` adalah starter code untuk bagian praktik apabila dosen memilih mode praktik berbasis coding.

## Catatan

Pertemuan 8 berfungsi sebagai evaluasi tengah semester. Materi teknis baru dilanjutkan pada Pertemuan 9 dengan topik MySQL dan operasi CRUD berbasis database.
