# Format Pengumpulan UTS

Format nama file:

```text
NIM_Nama_UTS_TI501.zip
```

Isi file ZIP:

```text
NIM_Nama_UTS_TI501/
├── src/
├── jawaban-uts.md
└── screenshot/
```

Catatan:

- Pastikan `npm install` dan `npm start` dapat dijalankan.
- Jangan mengumpulkan folder `node_modules`.
- Sertakan link GitHub apabila dosen meminta repository online.
