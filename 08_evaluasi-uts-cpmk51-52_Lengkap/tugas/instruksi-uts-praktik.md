# Instruksi UTS Praktik

Gunakan folder `src` sebagai starter code. Mahasiswa diminta melengkapi fitur berikut:

1. Menampilkan daftar produk dari endpoint `GET /api/produk`.
2. Membuat form tambah produk menggunakan HTML semantik.
3. Mengirim data produk baru ke endpoint `POST /api/produk` dengan Fetch API.
4. Menampilkan pesan sukses atau error dari response JSON.
5. Menata halaman agar responsif pada layar laptop dan ponsel.

## Output yang Dikumpulkan

- Folder source code.
- Screenshot halaman web.
- Screenshot uji API.
- Template jawaban yang sudah diisi.
