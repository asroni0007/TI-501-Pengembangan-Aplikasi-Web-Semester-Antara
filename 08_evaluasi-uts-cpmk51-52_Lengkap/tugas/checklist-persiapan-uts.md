# Checklist Persiapan UTS

Sebelum UTS, pastikan mahasiswa sudah memahami:

- Struktur HTML5 semantik.
- CSS box model, Flexbox, Grid, dan media query.
- Dasar UI/UX, wireframe, dan alur pengguna.
- DOM manipulation dan event handling.
- Fetch API dan JSON.
- Node.js, Express, route, middleware, dan static file serving.
- REST API, HTTP method, status code, kontrak endpoint, dan pengujian API.
