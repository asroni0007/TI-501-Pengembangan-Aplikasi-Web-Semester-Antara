Integrasi API Generatif/LLM

Mahasiswa belajar membuat fitur AI untuk menghasilkan caption promosi produk UMKM menggunakan backend Express.

POST /api/ai/generate-konten
{
  "produk_id": 1,
  "gaya": "ramah dan persuasif",
  "kanal": "Instagram"
}

Prinsip utama: API key disimpan di server melalui .env, bukan di frontend.
