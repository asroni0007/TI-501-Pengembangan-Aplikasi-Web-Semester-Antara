# Rubrik Penilaian Pertemuan 10

| Aspek | Bobot | Indikator |
|---|---:|---|
| Konfigurasi project | 20% | Aplikasi dapat dijalankan, database terkoneksi, `.env.example` tersedia. |
| Keamanan API key | 20% | API key tidak muncul di frontend dan tidak ditulis di source code publik. |
| Prompt engineering | 25% | Prompt memuat role, konteks produk, tugas, aturan output, dan batasan klaim. |
| Integrasi endpoint AI | 25% | Endpoint menerima input, memanggil service AI/mock, dan mengembalikan hasil JSON. |
| Dokumentasi dan pengujian | 10% | Screenshot, catatan pengujian, dan laporan singkat lengkap. |
