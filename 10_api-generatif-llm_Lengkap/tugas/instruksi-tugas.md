# Instruksi Tugas Pertemuan 10

Kembangkan fitur **Generate Konten Promosi AI** pada studi kasus Asisten AI untuk UMKM.

## Ketentuan

1. Jalankan database dari `src/database/schema.sql`.
2. Jalankan aplikasi Express dengan konfigurasi `.env`.
3. Gunakan mode `mock` terlebih dahulu sampai alur frontend-backend berhasil.
4. Opsional: aktifkan `gemini` atau `openai` jika memiliki API key.
5. Tampilkan hasil AI di halaman frontend.
6. Simpan hasil generate ke tabel `konten_ai`.
7. Sertakan screenshot:
   - halaman aplikasi;
   - response endpoint `/api/ai/generate-konten`;
   - isi tabel `konten_ai`.

## Output Dikumpulkan

- Source code yang sudah berjalan.
- File `.env.example`, bukan `.env` asli.
- Laporan singkat menggunakan `template-laporan.md`.
- Screenshot bukti pengujian.
