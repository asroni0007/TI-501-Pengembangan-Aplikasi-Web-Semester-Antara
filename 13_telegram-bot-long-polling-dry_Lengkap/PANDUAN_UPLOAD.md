# Panduan Upload Pertemuan 13 ke GitHub

Unggah folder ini ke repository dengan nama:

```text
13_telegram-bot-long-polling-dry
```

Struktur folder mengikuti paket pertemuan sebelumnya:

- `materi/` untuk slide perkuliahan;
- `panduan/` untuk panduan praktikum;
- `src/` untuk starter project Node.js + Express + Telegram bot;
- `assets/` untuk diagram pendukung;
- `tugas/` untuk instruksi, rubrik, checklist, dan template laporan;
- `demo-opsional/` untuk halaman ringkas pratinjau materi.

Sebelum digunakan di kelas, dosen dapat menyiapkan satu bot Telegram demo melalui BotFather agar alur long polling dapat ditunjukkan tanpa menunggu mahasiswa membuat token masing-masing.
