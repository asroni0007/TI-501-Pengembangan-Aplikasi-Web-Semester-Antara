# Checklist Praktikum Bot Polling

- [ ] Token Telegram disimpan di `.env`, bukan ditulis langsung di kode.
- [ ] Server Express dapat berjalan tanpa error.
- [ ] Bot dapat menerima pesan dari Telegram.
- [ ] Perintah `/start`, `/menu`, dan `/caption` berjalan.
- [ ] Offset update digunakan agar pesan tidak diproses berulang.
- [ ] Logic utama berada pada file service.
- [ ] Service dapat dipakai oleh REST API dan bot.
- [ ] Screenshot hasil pengujian sudah disiapkan.
