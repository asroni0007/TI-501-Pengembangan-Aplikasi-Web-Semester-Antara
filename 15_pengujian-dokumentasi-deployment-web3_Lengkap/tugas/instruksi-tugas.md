# Instruksi Tugas Pertemuan 15

## Judul
Testing, README, Deployment Preparation, dan Refleksi Web3 pada Asisten AI UMKM

## Tujuan
Mahasiswa mampu memastikan aplikasi lebih siap untuk demo akhir melalui pengujian otomatis, dokumentasi teknis, konfigurasi deployment, dan refleksi arsitektur.

## Langkah Pengerjaan

1. Jalankan starter project pada folder `src`.
2. Jalankan `npm test` dan pastikan semua test lulus.
3. Tambahkan minimal satu intent baru pada `services/assistantService.js`.
4. Tambahkan minimal satu test baru untuk intent tersebut.
5. Lengkapi README project dengan:
   - deskripsi aplikasi;
   - fitur utama;
   - cara instalasi;
   - daftar endpoint;
   - variabel `.env` yang dibutuhkan tanpa menulis nilai rahasia;
   - cara menjalankan test;
   - rencana deployment.
6. Siapkan konfigurasi deployment, misalnya `Procfile`, `Dockerfile`, atau konfigurasi platform yang digunakan.
7. Tulis refleksi singkat perbandingan client-server dan dApp/Web3.

## Output yang Dikumpulkan

- Link repository atau file zip project.
- Screenshot `npm test` lulus.
- Screenshot endpoint `/health` dan `/api/assistant`.
- README yang sudah dilengkapi.
- Laporan singkat menggunakan template yang tersedia.
