# Panduan Upload Pertemuan 15 ke GitHub

Unggah folder ini ke repository dengan nama:

```text
15_pengujian-dokumentasi-deployment-web3
```

Struktur folder mengikuti paket sebelumnya:

- `materi/` untuk slide;
- `panduan/` untuk panduan praktikum;
- `src/` untuk starter project Node.js + Express dengan automated test;
- `deployment/` untuk contoh berkas deployment;
- `assets/` untuk diagram;
- `tugas/` untuk instruksi, rubrik, checklist, dan template laporan;
- `demo-opsional/` untuk pratinjau materi.

Sebelum kelas, dosen dapat menyiapkan satu repository contoh agar mahasiswa melihat alur commit, test, README, dan deployment preparation secara utuh.
