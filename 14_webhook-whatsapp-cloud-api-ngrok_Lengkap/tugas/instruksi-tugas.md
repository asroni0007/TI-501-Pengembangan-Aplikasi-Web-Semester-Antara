# Instruksi Tugas Pertemuan 14

Buat pengembangan kecil pada starter project WhatsApp webhook berikut.

## Ketentuan

1. Jalankan server Express dan ngrok.
2. Tunjukkan hasil verifikasi webhook melalui request GET.
3. Simulasikan payload POST pesan WhatsApp melalui Postman atau curl.
4. Tambahkan satu intent baru pada `umkmAssistantService.js`, misalnya:
   - `promo` untuk menampilkan promo hari ini;
   - `alamat` untuk menampilkan alamat toko;
   - `jam buka` untuk menampilkan jam operasional.
5. Pastikan endpoint webhook tetap membalas HTTP 200 setelah menerima payload.
6. Dokumentasikan perbedaan polling dan webhook berdasarkan praktikum.

## Output Dikumpulkan

- Link repository atau folder project.
- Screenshot server berjalan.
- Screenshot ngrok aktif.
- Screenshot verifikasi webhook berhasil.
- Screenshot simulasi POST payload webhook.
- Penjelasan singkat perbedaan polling dan webhook.
