# Panduan Upload Pertemuan 14 ke GitHub

Unggah folder ini ke repository dengan nama:

```text
14_webhook-whatsapp-cloud-api-ngrok
```

Struktur folder mengikuti paket pertemuan sebelumnya:

- `materi/` untuk slide perkuliahan;
- `panduan/` untuk panduan praktikum;
- `src/` untuk starter project Node.js + Express + WhatsApp webhook;
- `assets/` untuk diagram pendukung;
- `tugas/` untuk instruksi, rubrik, checklist, dan template laporan;
- `demo-opsional/` untuk halaman ringkas pratinjau materi.

Sebelum kelas, dosen disarankan menyiapkan satu demo Meta Developer App dan satu akun ngrok agar proses verifikasi webhook dapat ditunjukkan secara langsung. Jika belum tersedia, praktikum tetap dapat memakai simulasi GET verification dan POST payload webhook melalui Postman.
