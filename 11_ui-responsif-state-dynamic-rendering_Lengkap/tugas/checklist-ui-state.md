# Checklist UI, State, dan Dynamic Rendering

- [ ] Navigasi dapat mengganti view aktif.
- [ ] State menyimpan `view`, `query`, `status`, dan data.
- [ ] Pencarian bekerja tanpa reload halaman.
- [ ] Filter status bekerja sesuai data.
- [ ] Kartu produk/konten dibuat dari array data.
- [ ] Badge berubah sesuai status data.
- [ ] Empty state muncul saat data kosong.
- [ ] Tampilan mobile tidak melebar dan tetap mudah dibaca.
