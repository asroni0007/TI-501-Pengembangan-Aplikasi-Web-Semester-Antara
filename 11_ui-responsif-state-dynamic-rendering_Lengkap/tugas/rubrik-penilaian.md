# Rubrik Penilaian Pertemuan 11

| Aspek | Bobot | Kriteria |
|---|---:|---|
| State management sederhana | 25% | State menyimpan view, query, filter, dan data secara jelas. |
| Dynamic rendering | 25% | UI dirender dari data, bukan ditulis manual berulang. |
| Komponen UI | 20% | Kartu, badge, empty state, dan summary rapi serta konsisten. |
| Responsivitas | 20% | Layout nyaman pada desktop dan smartphone. |
| Dokumentasi | 10% | Screenshot dan penjelasan perubahan lengkap. |
