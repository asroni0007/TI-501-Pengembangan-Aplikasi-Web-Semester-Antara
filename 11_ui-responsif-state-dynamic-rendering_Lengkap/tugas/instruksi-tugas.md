# Tugas Pertemuan 11

Lengkapi dashboard **Asisten AI untuk UMKM** agar memiliki UI responsif dan komponen berbasis data.

## Ketentuan

1. Tambahkan minimal 1 komponen kartu baru, misalnya kartu kategori, kartu statistik, atau kartu rekomendasi konten.
2. Tambahkan minimal 1 badge status baru, misalnya `perlu-review`, `stok-rendah`, atau `unggulan`.
3. Gunakan state sederhana untuk menyimpan view aktif, kata kunci pencarian, filter status, dan data yang sedang ditampilkan.
4. Pastikan tampilan responsif pada layar desktop dan smartphone.
5. Kumpulkan screenshot desktop, screenshot mobile, dan potongan kode `state`, `render`, serta event listener.

## Output Pengumpulan

- Link repository/folder hasil pekerjaan.
- Screenshot tampilan desktop dan mobile.
- Penjelasan singkat perubahan UI dan cara kerja state.
