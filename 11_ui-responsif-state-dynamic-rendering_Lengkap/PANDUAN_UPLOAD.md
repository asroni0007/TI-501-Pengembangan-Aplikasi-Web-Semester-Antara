# Panduan Upload Pertemuan 11 ke GitHub

Unggah folder ini ke root repository dengan nama:

```text
11_ui-responsif-state-dynamic-rendering
```

Struktur folder mengikuti paket Pertemuan sebelumnya:

- `materi/` untuk slide perkuliahan;
- `panduan/` untuk panduan praktikum;
- `src/` untuk starter project Express + frontend dinamis;
- `assets/` untuk diagram pendukung;
- `tugas/` untuk instruksi, rubrik, checklist, dan template laporan;
- `demo-opsional/` untuk halaman ringkas pratinjau materi.

Pastikan mahasiswa memahami bahwa fokus utama Pertemuan 11 adalah **frontend logic**, bukan pembuatan endpoint backend yang kompleks. Endpoint dummy disediakan untuk menjaga praktikum tetap cepat dan stabil.
