# Rubrik Penilaian UAS

| Aspek | Bobot | Indikator |
|---|---:|---|
| Implementasi fitur | 35% | Fitur inti berjalan, integrasi frontend-backend baik, database/API sesuai kebutuhan, alur aplikasi konsisten. |
| Demo dan alur pengguna | 25% | Demo lancar, skenario realistis, error tertangani, pengguna dapat memahami manfaat aplikasi. |
| Dokumentasi dan pengujian | 20% | README jelas, cara instalasi lengkap, endpoint terdokumentasi, bukti testing tersedia. |
| Presentasi dan kontribusi | 15% | Penyampaian runtut, pembagian peran jelas, setiap anggota memahami bagian yang dikerjakan. |
| Refleksi akhir | 5% | Mampu menjelaskan pembelajaran, kendala, keputusan teknis, dan rencana perbaikan. |

## Skala Nilai

- 85-100: sangat baik, aplikasi stabil dan dokumentasi kuat.
- 75-84: baik, aplikasi berjalan dengan beberapa catatan minor.
- 65-74: cukup, fitur inti ada namun integrasi atau dokumentasi belum lengkap.
- 55-64: kurang, aplikasi belum stabil dan bukti pengujian terbatas.
- <55: perlu perbaikan besar atau artefak utama tidak tersedia.
