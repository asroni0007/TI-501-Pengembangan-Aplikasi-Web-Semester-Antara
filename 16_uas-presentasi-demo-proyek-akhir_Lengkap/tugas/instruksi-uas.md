# Instruksi UAS Pertemuan 16

## Tema

Presentasi dan demo proyek akhir aplikasi web terintegrasi. Studi kasus yang disarankan: **Asisten AI untuk UMKM**.

## Ketentuan Presentasi

Setiap kelompok menyiapkan presentasi 7-10 slide dengan isi minimal:

1. masalah dan kebutuhan pengguna;
2. rancangan solusi dan arsitektur aplikasi;
3. fitur utama yang sudah berjalan;
4. struktur database dan endpoint API;
5. integrasi AI/chatbot bila ada;
6. aspek keamanan dan validasi input;
7. pengujian dan dokumentasi;
8. link repository dan deployment;
9. kontribusi anggota kelompok;
10. kendala dan rencana pengembangan.

## Ketentuan Demo

Demo dilakukan menggunakan data contoh yang sudah disiapkan. Hindari mengetik data panjang saat presentasi. Sediakan video cadangan apabila koneksi internet tidak stabil.

## Berkas yang Dikumpulkan

- Link GitHub repository.
- Link aplikasi live atau video demo.
- README final.
- Laporan final singkat.
- Screenshot pengujian.
- Screenshot deployment/configuration tanpa memperlihatkan secret.
