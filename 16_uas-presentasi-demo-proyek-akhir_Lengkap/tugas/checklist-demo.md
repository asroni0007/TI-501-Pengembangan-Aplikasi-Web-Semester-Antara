# Checklist Demo UAS

## Sebelum Presentasi

- [ ] Repository GitHub dapat dibuka.
- [ ] README final sudah diperbarui.
- [ ] Aplikasi dapat dijalankan lokal.
- [ ] Link deployment atau video demo tersedia.
- [ ] Data demo sudah disiapkan.
- [ ] File `.env` tidak ikut terunggah.
- [ ] Screenshot pengujian tersedia.
- [ ] Pembagian peran anggota sudah disepakati.

## Saat Demo

- [ ] Menjelaskan masalah pengguna.
- [ ] Menjalankan fitur utama dari awal sampai akhir.
- [ ] Menunjukkan API/backend bila relevan.
- [ ] Menunjukkan data tersimpan di database.
- [ ] Menunjukkan validasi input dan error handling.
- [ ] Menunjukkan dokumentasi dan test.
- [ ] Menjawab pertanyaan teknis secara singkat dan jelas.

## Setelah Demo

- [ ] Mengumpulkan link dan laporan final.
- [ ] Mengisi refleksi kontribusi anggota.
- [ ] Menuliskan kendala dan rencana pengembangan.
