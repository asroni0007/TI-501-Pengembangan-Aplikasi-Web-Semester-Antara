# Pertemuan 16 — UAS: Presentasi, Demo, Evaluasi, dan Refleksi Proyek Akhir

**TI-501 Pengembangan Aplikasi Web · CPMK51, CPMK52, CPMK53**

Pertemuan 16 digunakan untuk evaluasi akhir berbasis proyek. Mahasiswa mempresentasikan dan mendemonstrasikan aplikasi web terintegrasi yang telah dibangun selama perkuliahan, misalnya studi kasus **Asisten AI untuk UMKM**.

## Capaian Pembelajaran

Mahasiswa mampu:

1. mempresentasikan rancangan, implementasi, dan hasil pengujian aplikasi web;
2. mendemonstrasikan integrasi frontend, backend, database, API, chatbot, keamanan, dan deployment;
3. menjelaskan kontribusi setiap anggota tim secara objektif;
4. menyusun refleksi teknis dan rencana pengembangan lanjutan;
5. menunjukkan ketercapaian CPMK51, CPMK52, dan CPMK53 melalui artefak proyek.

## Kesesuaian RPS

Pertemuan 16 berfungsi sebagai evaluasi akhir/UAS yang mengukur capaian menyeluruh:

- CPMK51: struktur antarmuka web, HTML/CSS/JavaScript, dan UI responsif;
- CPMK52: backend Node.js/Express, REST API, database, dan integrasi layanan;
- CPMK53: keamanan dasar, pengujian, dokumentasi, deployment, dan presentasi teknis.

## Skema Pelaksanaan Kelas

- Pembukaan dan pengarahan UAS: 10 menit.
- Presentasi dan demo tiap kelompok: 10-15 menit.
- Tanya jawab dan verifikasi artefak: 5 menit per kelompok.
- Refleksi akhir dan penutup: 10 menit.

## Output yang Dikumpulkan

1. Link repository GitHub.
2. Link deployment atau video demo apabila deployment belum stabil.
3. README final.
4. Bukti pengujian otomatis atau manual.
5. Laporan final singkat.
6. Refleksi kontribusi anggota.
