# Panduan Upload Pertemuan 16 ke GitHub

Unggah folder ini ke repository dengan nama:

```text
16_uas-presentasi-demo-proyek-akhir
```

Struktur folder mengikuti paket pertemuan sebelumnya:

- `materi/` untuk slide UAS;
- `panduan/` untuk panduan pelaksanaan UAS;
- `tugas/` untuk instruksi, rubrik, checklist, dan template laporan;
- `penilaian/` untuk format penilaian dosen;
- `src/` untuk template README final project dan contoh konfigurasi produksi;
- `assets/` untuk diagram;
- `demo-opsional/` untuk halaman ringkas arahan UAS.

Dosen dapat menyesuaikan durasi presentasi berdasarkan jumlah kelompok dan waktu kelas yang tersedia.
