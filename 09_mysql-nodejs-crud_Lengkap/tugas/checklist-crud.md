# Checklist CRUD Pertemuan 9

Gunakan checklist ini sebelum mengumpulkan tugas.

- [ ] Database `asisten_ai_umkm` berhasil dibuat.
- [ ] Tabel `kategori` dan `produk` tersedia.
- [ ] Data awal berhasil masuk dari `schema.sql`.
- [ ] File `.env` sudah dikonfigurasi dan tidak diunggah ke repository publik.
- [ ] `GET /api/status` menunjukkan server dan database aktif.
- [ ] `GET /api/produk` menampilkan data dari MySQL.
- [ ] `GET /api/produk/:id` menampilkan detail produk.
- [ ] `POST /api/produk` dapat menambah data baru.
- [ ] `PUT /api/produk/:id` dapat memperbarui data.
- [ ] `DELETE /api/produk/:id` dapat menghapus data.
- [ ] Query SQL menggunakan placeholder `?`.
- [ ] Halaman frontend dapat memuat data produk.
