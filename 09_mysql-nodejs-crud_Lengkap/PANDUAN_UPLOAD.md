# Panduan Upload Pertemuan 9 ke GitHub

Unggah folder ini ke root repository dengan nama:

```text
09_mysql-nodejs-crud
```

Struktur folder disamakan dengan Pertemuan sebelumnya:

- `materi/` untuk slide perkuliahan;
- `panduan/` untuk panduan praktikum;
- `src/` untuk starter project Node.js, Express, dan MySQL;
- `assets/` untuk diagram pendukung;
- `tugas/` untuk instruksi, rubrik, checklist, dan template laporan;
- `demo-opsional/` untuk halaman ringkas pratinjau materi.

Sebelum dibagikan kepada mahasiswa, pastikan file `.env` asli tidak ikut diunggah. Gunakan `.env.example` sebagai contoh konfigurasi.
