# Panduan Upload Pertemuan 7 ke GitHub

Unggah folder ini ke root repository dengan nama:

```text
07_rest-api-http-method-endpoint-json
```

Struktur folder disamakan dengan Pertemuan 1–6:

- `materi/` untuk slide PPT;
- `panduan/` untuk dokumen praktikum;
- `src/` untuk source code praktikum;
- `tugas/` untuk instruksi, rubrik, checklist, dan template laporan;
- `assets/` untuk diagram pendukung;
- `demo-opsional/` untuk demo visual tambahan.

Setelah upload, pastikan file `README.md` tampil di GitHub dan perintah `npm install` serta `npm run dev` dapat diikuti mahasiswa.
