# Rubrik Penilaian Pertemuan 7

| Aspek | Bobot | Kriteria |
|---|---:|---|
| Desain endpoint REST | 20% | Resource, path, dan method disusun jelas dan konsisten. |
| Implementasi HTTP method | 25% | GET, POST, PUT, dan DELETE berjalan sesuai fungsi CRUD. |
| Format JSON dan status code | 20% | Response sukses/error konsisten, mudah dibaca, dan memakai status code tepat. |
| Validasi request body | 15% | Input penting divalidasi dan error dikirim dalam format JSON. |
| Pengujian API | 10% | Screenshot/hasil uji endpoint lengkap dan dapat direplikasi. |
| Kerapian laporan dan source | 10% | Struktur folder rapi, kode terbaca, dan laporan menjelaskan kontrak endpoint. |
