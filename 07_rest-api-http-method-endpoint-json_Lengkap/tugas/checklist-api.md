# Checklist Validasi Pertemuan 7

- [ ] `npm install` berhasil.
- [ ] `npm run dev` berjalan tanpa error.
- [ ] Halaman frontend tampil di `http://localhost:3000`.
- [ ] `GET /api/status` mengirim status API.
- [ ] `GET /api/produk` mengirim daftar produk.
- [ ] `GET /api/produk/:id` mengirim satu produk atau 404 jika tidak ditemukan.
- [ ] `POST /api/produk` dapat menambah produk dari JSON body.
- [ ] `PUT /api/produk/:id` dapat mengubah produk.
- [ ] `DELETE /api/produk/:id` dapat menghapus produk.
- [ ] Response error memakai JSON, bukan HTML error bawaan.
- [ ] Status code 200, 201, 400, dan 404 dapat dijelaskan.
- [ ] Kontrak endpoint ditulis di laporan.
- [ ] Screenshot pengujian endpoint disertakan.
