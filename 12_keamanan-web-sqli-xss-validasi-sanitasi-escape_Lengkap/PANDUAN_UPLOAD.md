# Panduan Upload Pertemuan 12

1. Unggah folder ini utuh agar tautan relatif tidak rusak.
2. Pertahankan nama folder `12_keamanan-web-sqli-xss-validasi-sanitasi-escape_Lengkap`.
3. Jangan mengunggah file `.env`, kredensial, token, atau data pengguna nyata.
4. File yang aman diunggah: `.env.example`, source code, materi, panduan, aset, dan tugas.
5. Sebelum commit, jalankan `npm test` dan `npm audit --omit=dev`.
6. Pesan commit yang disarankan: `Add pertemuan 12 keamanan web SQLi dan XSS`.
